# Agents

AI agent instruction sets and configurations for automated workflows.

## Available Agents

| Agent | Purpose |
|-------|----------|
| Post-hoc Analyzer Agent | Evaluates outputs against expectations and provides feedback |
| email-agent | Automates email composition and management |
| Compare two outputs WITHOUT knowing which skill produced them_AGENT | Blind evaluation and comparison of skill outputs |
| arch-usb-agent-instructions | Automated setup and configuration for Arch Linux USB devices |

## How to Use

1. Select an agent instruction file
2. Customize parameters for your use case
3. Load into your Claude Code environment
4. Monitor outputs and provide feedback for improvement

## Creating New Agents

See `/templates/Skill Creator.md` for framework to create new agents.
