# Templates

Templates and builders for creating new content and skills.

## Available Templates

| Template | Purpose |
|----------|----------|
| Skill Creator | Framework and methodology for creating new skills |
| Web Artifacts Builder | Builder for creating web-based interactive artifacts |

## Creating New Skills

Follow the **Skill Creator** guide to:
1. Define skill objectives
2. Create instruction sets
3. Configure parameters
4. Build evaluation criteria
5. Package for distribution

## Creating Web Artifacts

Use **Web Artifacts Builder** to:
1. Design interactive web interfaces
2. Build HTML/CSS/JavaScript components
3. Test responsiveness
4. Package as standalone artifacts

## Integration

- See `/agents/Post-hoc Analyzer Agent.md` to evaluate your creations
- Use `/evaluation` tools to validate outputs
- Reference `/guides` for best practices
