# GOOGLE DRIVE SETUP GUIDE — STEP BY STEP
## Upload All Documents to Google Drive
**Time:** 20–30 minutes | **Cost:** Free (15GB storage) | **Difficulty:** Beginner-friendly (no technical skills needed)

---

## WHAT YOU'LL END UP WITH

All documents organized in a Google Drive folder, accessible from any device, automatically backed up.

---

## PREREQUISITES

### 1. Google Account
- **Do you have one?**
  - ✅ Yes → Skip to Step 1
  - ❌ No → Go to accounts.google.com/signup → Create account (free)

### 2. Internet Connection
- Stable WiFi or broadband recommended (large files uploading)

---

## STEP 1: OPEN GOOGLE DRIVE

1. Open web browser
2. Go to: `drive.google.com`
3. Log in with your Google account

---

## STEP 2: CREATE MAIN FOLDER

1. Click "New" button (top left, blue)
2. Select "Folder"
3. Name it: `your-project-documents`
4. Click "Create"
5. Double-click to enter the folder

---

## STEP 3: CREATE SUBFOLDERS

Inside your main folder, create subfolders:

1. Click "New" (blue button)
2. Select "Folder"
3. Repeat for each subfolder:

```
01_DOCS
02_MEDICAL
03_REGULATORY
04_CAREER
05_PERSONAL
06_SKILLS
07_TOOLS
08_RESEARCH
```

---

## STEP 4: UPLOAD FILES TO CORRECT FOLDERS

**Strategy:** Upload files category by category.

1. Double-click the target subfolder
2. Click "New" → "File upload"
3. Select your files (hold Ctrl/Cmd to select multiple)
4. Click "Open" and wait for upload
5. Click back to main folder (breadcrumb at top)

---

## STEP 5: SET PERMISSIONS (IMPORTANT)

### Private (Only You):
- Right-click main folder
- Select "Share"
- Set to "Restricted"

### Share with Specific People:
- Right-click main folder → "Share"
- Add specific emails
- Choose: "Viewer" (read only) or "Editor" (can modify)

### Public (Anyone with Link):
- Right-click → "Share"
- Click "Change to anyone with link"
- Click "Copy link"

---

## STEP 6: VERIFY EVERYTHING UPLOADED

1. Double-click each subfolder
2. Verify all expected files are there
3. Check file sizes match

---

## ALTERNATIVE: BULK UPLOAD

If all files are already in one folder:

1. Create the subfolders first
2. Click "New" → "File upload"
3. Select **all files at once** (Ctrl+A)
4. Wait for all to upload
5. Manually drag files into correct subfolders

---

## ADVANCED: SYNC GOOGLE DRIVE WITH COMPUTER

1. Download "Google Drive for desktop" from drive.google.com/download
2. Install on your computer
3. Sign in with Google account
4. Files automatically sync

---

## TROUBLESHOOTING

| Problem | Solution |
|---------|----------|
| Upload stuck | Check internet; upload fewer files at once |
| Can't find folder | Search: click magnifying glass, type folder name |
| Move file to another folder | Right-click → "Move" → Choose destination |
| Delete something by mistake | Check "Trash" — recoverable for 30 days |

---

## COMPARISON: GOOGLE DRIVE VS. GITHUB

| Feature | Google Drive | GitHub |
|---------|-------------|--------|
| Easy to use | ✅ Yes | ⚠️ Requires terminal |
| Version control | Basic | ✅ Full history |
| Sharing | ✅ Easy | Requires account |
| Large files | ✅ Yes (5TB) | Limit 100MB per file |
| Security | Good | ✅ Very good |

**Best approach:** Use BOTH
- **Google Drive:** Primary storage, easy backup/sharing
- **GitHub:** Version control, code/scripts, public portfolio
