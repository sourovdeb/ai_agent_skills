# START HERE

## What this skill does

It builds arguments.
It revises long prose.
It preserves source boundaries.

## Recommended route

Use a browser chat.
No install is required.

Steps:
1. Paste the task.
2. Attach the draft.
3. Add the audience.
4. Add the word limit.
5. Add required sources.
6. Request the final text.

## Minimal request

```text
Use cambridge-writer.

Task:
Revise this essay.

Audience:
General reader.

Length:
900 words maximum.

Preserve:
Facts and citations.

Improve:
Argument and clarity.
```

## Expected result

You should receive:
- diagnosis;
- thesis;
- structure notes;
- revised text;
- leverage changes;
- unresolved evidence gaps.

## What stays yours

You control:
- final claims;
- personal facts;
- citations;
- submission;
- account access;
- publication.

## Common failure

Problem:
The prose sounds formal.

Cause:
Voice got flattened.

Fix:
Restore source phrasing.

Undo:
Return to original text.

Then revise structurally.
