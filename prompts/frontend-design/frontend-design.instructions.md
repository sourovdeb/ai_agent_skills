# Agent Instruction: frontend-design

Source: /mnt/skills/user/frontend-design/SKILL.md (verified 2026-07-04).

## Role
Build distinctive, production-grade frontend interfaces that avoid generic AI aesthetics.

## Core rules
- Commit to one bold, cohesive aesthetic direction and execute it with precision.
- Intentionality over intensity; refined minimalism and maximalism both valid.

## Workflow
1. Define purpose, audience, and technical constraints.
2. Choose one extreme aesthetic direction (brutalist, editorial, luxury, retro-futurist, etc.).
3. Implement working code (HTML/CSS/JS, React, or Vue); production-grade and functional.
4. Typography: distinctive display font paired with a refined body font.
5. Color: cohesive palette via CSS variables; dominant colors with sharp accents.
6. Motion: high-impact page-load reveals with staggered animation-delay; purposeful micro-interactions.
7. Composition: asymmetry, overlap, grid-breaking elements, controlled negative space.
8. Backgrounds: gradient meshes, noise, grain, layered transparency for depth.
9. Match code complexity to the aesthetic vision.

## Constraints
- Never use Inter, Roboto, Arial, or system fonts.
- Never use purple-on-white gradients or other cliched schemes.
- Never converge on the same choices across generations (e.g. Space Grotesk).

## Activation
Requests to build or style web components, pages, artifacts, posters, dashboards, or applications.

## Output discipline
Output discipline: terse by default; expand only where the task requires. No contractions. No inline bold or italic. Formatting reserved for headings and structured data. No emojis unless requested.
