# Methods Registry

Choose the lightest method that fits. Escalate one rung at a time.

| # | Method | Mechanism | Source | Fits when | Effort |
|---|---|---|---|---|---|
| 1 | Free-list burst | Timed quantity-first listing, judgment deferred | Osborn 1953 (rules); nominal generation per Diehl and Stroebe 1987 | Any open question; default start | Minutes |
| 2 | Brainwriting 6-3-5 (solo-AI variant) | Parallel written streams; agent generates independent sets, then builds on each | Rohrbach 1968; Paulus and Yang 2000 | Stalled free-list; need volume without anchoring | Minutes |
| 3 | SCAMPER | Transform verbs on an existing idea or artifact: Substitute, Combine, Adapt, Modify, Put to other use, Eliminate, Reverse | Eberle 1971, extending Osborn's checklist | Improving or varying something that already exists | Minutes |
| 4 | Morphological grid | Decompose problem into independent dimensions; enumerate values; combine cells | Zwicky 1969 | Problem has 2–4 separable parameters (format × audience × channel) | Moderate |
| 5 | Constraint injection | Add an artificial constraint (halve the budget, remove the main tool, ten-minute version) and regenerate | Documented practitioner method; TIER-4 label | Ideas converge too early; need novelty | Minutes |
| 6 | Reverse brainstorm | Generate ways to cause the failure, then invert each | Documented practitioner method; TIER-4 label | Risk-heavy problems; prevention framing | Minutes |
| 7 | TRIZ contradiction check | Identify the improving-versus-worsening parameter pair; consult inventive-principle patterns | Altshuller | Technical or engineering trade-off problems | High |
| 8 | Nominal Group Technique (multi-person) | Silent independent generation, round-robin sharing, silent voting | Delbecq et al. | Real group present; meeting facilitation | Moderate |

## Convergence instruments

- Criteria matrix: options as rows, Step 0 criteria as columns, integer scores, sum with stated weights. The only load-bearing ranking device.
- Effort-impact screen: plot or rank score against execution effort; select high-score low-effort first. TIER-4 practitioner method; use as ordering aid, not proof.
- Dot-vote (group settings only): each participant allocates fixed votes after silent review.

## Anti-patterns (documented failure modes)

- Serial spoken group generation without structure: production blocking halves output (Diehl and Stroebe 1987).
- Evaluating during generation: suppresses quantity (Osborn 1953, rule of deferred judgment).
- First-idea anchoring: counter with method 5 or a second independent burst.
- Ranking without pre-declared criteria: produces preference dressed as analysis; prohibited.

## Worked micro-example (user domain)

Problem: easiest efficient method to produce one ELT lesson-plan draft per day.
Step 0 criteria: under 20 minutes · reuses existing assets · CELTA-consistent staging. Method: SCAMPER on the existing template (Adapt: swap context; Eliminate: cut one stage for revision days; Combine: pair reading text with existing vocabulary set). Convergent screen scores template-transform highest on all three criteria; full-regeneration lowest on time.
