# Deep Brainstorm

Generate ideas that survive scrutiny — multi-method, multi-perspective, dual-horizon — for any domain.

## Core rule: obvious ideas are the floor, not the output

First write the five ideas anyone would produce. Mark them BASELINE. They are excluded from delivery unless they outrank later ideas at Step 6. Rationale — later ideas trend more original (documented serial-order effect in creativity research; RECOLLECTION-ONLY).

## The pass

**0. Frame.** One table: subject · goal · hard constraints · domain · horizons (immediate / 1 year / 5+ years) · success criteria (3–5, measurable) · rank weights if the user supplies them.

**1. Baseline purge.** Five obvious ideas → BASELINE.

**2. Diverge.** Apply at least three methods; pick by fit:

| Method | Origin | Use when |
|---|---|---|
| SCAMPER | Eberle, from Osborn's checklists | Improving an existing thing |
| Inversion | Jacobi / Munger | How would this fail on purpose → reverse |
| First principles | classical decomposition | Assumptions suspect; rebuild from costs/physics/law |
| Morphological matrix | Zwicky | Problem splits into parameters × options |
| Cross-domain analogy | structure-mapping research | Steal a working structure from an unrelated field |
| Constraint injection | creativity-under-constraints research | Halve the budget/time, then 10× it |
| Pre-mortem | Klein, 2007 | Assume failure in 12 months; list causes; invert |
| TRIZ contradictions | Altshuller | Technical trade-off (stronger but lighter) |
| Solo brainwriting | adapted from Rohrbach 6-3-5 | Three silent persona passes, merged after |

**3. Perspective rotation.** Minimum four lenses per promising idea: end user · adversary or competitor · regulator or auditor · financier · the operator who maintains it · future self at each horizon · de Bono-style facts / risk / upside / process.

**4. Horizon + second-order pass.** Each idea: short-term effect, long-term effect, then and then what twice (second-level thinking, Marks).

**5. Concreteness gate.** An idea survives only with: first physical action · rough cost · main risk · reversibility (reversible / costly / irreversible) · precedent or source where one exists, labeled DOCUMENTED / RECOLLECTION-ONLY / INFERRED. No gate fields, no delivery.

**6. Rank.** Default weights — impact 0.30 · feasibility 0.25 · time-to-value 0.20 · cost 0.15 · reversibility 0.10. User weights replace defaults. Irreversible, deadline-bound items override rank order regardless of score.

**7. Output.** Table: # · idea · horizon · first action · cost · risk · reversibility · label · score. Flag top 3 for an optional self-debate pass.

## Domain gates

- Health — ideas and research directions only; clinical decisions route to the user's treating clinicians; no dosing, diagnosis, or treatment selection.
- Legal — surface limitation periods and irreversible deadlines before ideation; positions require professional confirmation; statutes cited or labeled RECOLLECTION-ONLY.
- Finance — options with risk framing; never trade, product, or allocation recommendations.

## Stop criterion

Stop when three consecutive method passes add nothing that survives the concreteness gate, or the requested count is met. Do not pad.

## Anti-patterns

- Synonyms counted as separate ideas.
- Listicle output missing gate fields.
- Delivering BASELINE ideas as findings.
- Bending a stated constraint to rescue an idea.
- Speculation formatted as fact — label it or cut it.
