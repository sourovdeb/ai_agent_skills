# Superpowers Lab

Experimental, bleeding-edge development environment for the Superpowers ecosystem. Best for test-driving newly engineered features before they achieve production stability.

## Natural Triggers
- "test new features"
- "experimental mode"
- "bleeding edge"
- "try new workflow"
- "test drive"
- "preview features"
- "unstable version"
- "development build"

## Purpose

This skill provides access to cutting-edge functionality that is still under development. Use it when:
- You need features not yet available in the stable Superpowers skill
- You want to test upcoming functionality
- You're willing to accept potential instability for early access

## Usage Guidelines

### When to Use
- Testing new Superpowers features
- Providing feedback on experimental functionality
- Exploring upcoming capabilities
- Validating new workflows before production

### When NOT to Use
- Production-critical tasks
- Stable, reliable operations
- Mission-critical workflows
- When stability is paramount

## Relationship to Superpowers

- **Superpowers**: Stable, production-ready skill set
- **Superpowers Lab**: Experimental, cutting-edge features
- Features graduate from Lab to Superpowers after testing and stabilization

## Feedback

When using Superpowers Lab, provide feedback on:
- Feature usability
- Bugs and issues
- Performance characteristics
- Suggested improvements

## References
- Repository: https://github.com/obra/superpowers-lab

## Migration Path

Features in Superpowers Lab may:
- Graduate to stable Superpowers
- Be modified based on feedback
- Be removed if deemed unsuitable
- Change significantly between versions

Always check the repository for the latest status of experimental features.
