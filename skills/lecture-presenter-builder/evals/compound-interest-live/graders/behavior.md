# Pass criteria
- Has a presenter script and a separate audience-facing visual layer.
- Includes an actual step sequence or quantity diagram, not only a visual description.
- Calculation is correct and all hypothetical values are labelled.
- Shows the calculation fully before inviting practice.
- Gives the learner a concrete reason to care without hype.
- Screen content is not a transcript of the spoken script.
- Sources are real and linked, or assumptions are stated.
- Length is plausible for ten minutes, without padding.
