# lecture-presenter-builder

Creates a lecture for the instructor to read aloud while displaying a separate, sparse visual sequence. It is not a student-notes generator.

- `SKILL.md` — workflow and quality gates.
- `references/presenter-template.md` — output structure.
- `references/source-workflow.md` — user material, research, and citations.
- `references/methods.md` — instructional design grounding and limits.
- `evals/` — five prompt cases and grading criteria.
- `TESTING.md` — validation and behaviour testing.

Core rule: separate **PRESENTER ONLY** from **SHOW THE AUDIENCE**. Show actual diagrams or build-ready visuals; do not replace them with descriptions.
