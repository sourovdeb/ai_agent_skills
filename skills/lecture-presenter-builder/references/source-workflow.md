# Source workflow

## Ask for materials without creating a roadblock

When the request could benefit from user-owned material, offer one concise invitation:

> Do you have a document, link, book chapter, syllabus, existing slide deck, or image to build from? Upload it or share the link. Otherwise, I can research the topic and add complementary sources.

Do not repeat the question if the user has already answered. Do not block on optional materials. If the user asks for a specific chapter or document that is not accessible, ask them to upload it or paste the relevant text; never pretend to know its contents.

## Read and classify

1. Start with the user's material when it is accessible.
2. Record its title, author or institution, date, and relevant sections.
3. Separate the user's core source from supplementary sources found for verification or context.
4. Check factual claims against the source itself, not only search snippets.
5. If a URL or file cannot be read, name the access limitation and ask for an upload or excerpt when necessary.

## Research priority

1. Primary data, legislation, official guidance, research papers, original documents.
2. Academic publishers, professional associations, public research institutions, recognised reference works.
3. Reputable explanatory sources for context.
4. Forums and personal accounts only when lived experience or public reaction is directly relevant, and label them as such.

For current or consequential topics, check dates, jurisdiction, population, and scope. Prefer the primary source for a rule or statistic. Use recent sources for changes, and foundational sources for enduring concepts. Do not treat an abstract as proof of details that only appear in the full text.

## Citation method

- Mark sources inside the presenter script as `[S1]`, `[S2]`, and so on.
- In the source list, give the author or institution, title, date, URL, and the claims or beat supported.
- Put source details in the presenter-only layer unless the audience needs to see attribution.
- Distinguish direct quotation from paraphrase. Keep quotations short and preserve their meaning.
- Never invent page numbers, DOI details, dates, quotes, statistics, or reference metadata.
- Mark claims that remain unverified, explain the limitation, and avoid presenting them as settled facts.

## Complementary visual assets

When an image, chart, map, or video would add meaning, prefer official or openly licensed assets. Record creator, source, licence, and any attribution required. If no usable asset is available, give a build-ready diagram or label an image as a suggested asset—not as something already acquired. Never imply that an image is licensed when its terms are unknown.
