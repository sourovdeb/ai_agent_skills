# lecture-notes-builder

A visual-first skill for adult beginners.

- `SKILL.md`: operating rules and quality gates.
- `references/output-template.md`: compact output skeleton.
- `references/methods.md`: research basis and limits.
- `evals/`: five case-folder tests, each with a prompt and grader.
- `TESTING.md`: validation and evaluation workflow.

Core design rule: show the visual itself. A description of a visual does not satisfy the requirement.
