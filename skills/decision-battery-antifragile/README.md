# decision-battery-antifragile

Antifragile Decision Operating System for personal, family, and professional goals.

**What it is**: A 42-step (core) evidence-based decision process extending the original decision-battery.md. It forces:
- Debiasing (12-bias checklist, outside view, affect audit, self-distancing, consider-opposite, incentive audit)
- SCAMPER mutation (add/change/eliminate/reverse on options AND the process itself)
- Corporate risk discipline (FMEA, sensitivity, barbell allocation)
- Black swan / ruin separation + early-warning indicators + throw-away ritual
- ND-first design for ADHD/bipolar/depression brains: mandatory energy gates, somatic checks, chunked phases, light mode, exit ramps, if-then low-energy paths

**Integrations**: Hooks for prompt-architect (framing), socratic-self-review (key gates), consult-agent (stuck), brainstorm-agent (option generation).

**When to use**: Any consequential decision where bias, feelings, or attachment risk poor outcome or missed pivot. Type 1 doors especially. Weekly review or pre-commitment device.

**Files**:
- `SKILL.md` — full invocable Grok skill (drop in ~/.grok/skills/ or use via agent)
- Original decision-battery.md for reference

**GitHub accountability**: Every use should produce an OUTCOME-LOG appended to this repo (issue or PR comment) so the skill self-improves publicly.

**First 48h test (per brainstorm verdict)**: Run Light mode or 8-step core on one real micro-decision (e.g. tutoring package pricing or next CELTA appeal action). Log energy, SCAMPER used, kill criteria set.
