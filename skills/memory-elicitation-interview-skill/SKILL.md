# Memory Elicitation Interview

Not every project is a biography. Sometimes what's wanted — and what's actually achievable in one sitting — is one memory, done well, rather than a life's arc done thinly. This skill is the right-sized tool for that: same elicitation technique as the full biography kits, deliberately narrow scope.

Read `../biography-memoir-system/references/interview-methodology.md` for the core technique (sensory cueing, timeline anchoring, following the flicker, reliability coding) — this skill applies it within a single tight topic rather than across a whole life.

## Scoping the session before you start

Get specific about the target before diving in — vague scope ("tell me about the war") produces the same generic, rehearsed answer a full-biography interview would get on the same topic. Narrow it with the narrator up front:
- A specific event ("the day you left for the crossing")
- A specific person ("what Grandpa Hassan was actually like, day to day")
- A specific short period ("your first six months in this country")

## Technique, applied at this scale

- **Start wide within the narrow topic, then anchor immediately.** "What do you remember about that day" is fine as an opener, but move fast to a specific sensory or spatial anchor once anything surfaces — smell, sound, who else was there, what they were wearing.
- **One good session is often enough — resist stretching it.** Because the scope is narrow, a single 30-60 minute conversation frequently exhausts what's readily recallable. A second session, if wanted, is better scheduled for a different day than pushed through in one long sitting past the point of real recall (fatigue produces reconstruction dressed up as memory, which is worth flagging with a reliability tag if it happens).
- **Corroborate lightly if the memory matters historically.** If the memory intersects with a documentable event (a specific ship, a specific date, a historical event), it's worth a light corroboration pass afterward — see `skills/content-research-writer` if the project wants citation-grade sourcing — but don't interrupt the interview itself to fact-check in the moment; let the memory come out first.

## Output

A short, tightly-focused account with reliability tags, written up close to the narrator's actual words rather than heavily smoothed — the value of this format is precision on one thing, not breadth. If it later becomes part of a larger project, it can feed into `biography-interview-kit-private-master` or `dual-biography-interview-skill-v2` as one era's material rather than being redone from scratch.
