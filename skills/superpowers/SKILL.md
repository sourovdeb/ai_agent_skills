# Superpowers

The 'Swiss Army knife' of custom skills. Coordinates brainstorming, debugging, TDD enforcement, and multi-step execution planning natively via custom slash commands.

## Natural Triggers
- "execute this plan"
- "run this workflow"
- "debug this systematically"
- "follow TDD approach"
- "multi-step execution"
- "coordinate tasks"
- "slash command"
- "/execute-plan"

## Core Capabilities

### Brainstorming
- Guides unstructured ideation into concrete plans
- Acts as analytical sparring partner
- Generates multiple approaches and lets user curate

### Debugging
- Enforces systematic root-cause analysis
- Prevents shallow, unverified quick fixes
- Mandates step-by-step analysis based on telemetry and logs

### TDD Enforcement
- Strictly enforces test-first architectural patterns
- Restricts shifting to functional code until tests are written
- Ensures robust test specifications before implementation

### Multi-step Execution Planning
- Coordinates complex workflows
- Manages task dependencies
- Optimizes execution order

## Usage

Use slash commands to trigger specific behaviors:
- `/execute-plan` - Execute a predefined plan
- `/brainstorm` - Start brainstorming session
- `/debug` - Begin systematic debugging
- `/tdd` - Enforce test-driven development

## Best Practices
- Always define clear objectives before execution
- Break complex tasks into smaller, manageable steps
- Document assumptions and constraints upfront
- Validate each step before proceeding to the next
