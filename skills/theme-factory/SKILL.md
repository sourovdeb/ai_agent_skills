# Theme Factory Skill

This skill provides a curated collection of professional font and color themes, each with carefully selected color palettes and font pairings. Once a theme is chosen, it can be applied to any artifact.

## Purpose
To apply consistent, professional styling to presentation slide decks, documents and other artifacts. Each theme includes a cohesive color palette with hex codes, complementary font pairings for headers and body text, and a distinct visual identity suitable for different contexts and audiences.

## Usage Instructions
To apply styling to a slide deck or other artifact:
1. Show the theme showcase by displaying the available themes from references/theme-details.md or assets/theme-showcase.pdf if present. List the 10 themes with short descriptions for user selection.
2. Ask for their choice of theme name (e.g. Ocean Depths, Tech Innovation).
3. Wait for explicit selection and confirmation.
4. Once chosen, read the corresponding theme specification from references/theme-details.md
5. Apply the selected theme's colors (hex codes) and fonts consistently throughout the artifact using the appropriate editing skill (e.g. pptx, docx).
6. Ensure proper contrast, readability and maintain the theme's visual identity across all elements.

## Themes Available
The following 10 themes are available. Full specifications including hex codes and typography are in references/theme-details.md:
1. Ocean Depths - Professional and calming maritime theme
2. Sunset Boulevard - Warm and vibrant sunset colors
3. Forest Canopy - Natural and grounded earth tones
4. Modern Minimalist - Clean and contemporary grayscale
5. Golden Hour - Rich and warm autumnal palette
6. Arctic Frost - Cool and crisp winter-inspired theme
7. Desert Rose - Soft and sophisticated dusty tones
8. Tech Innovation - Bold and modern tech aesthetic
9. Botanical Garden - Fresh and organic garden colors
10. Midnight Galaxy - Dramatic and cosmic deep tones

## Application Process
After a preferred theme is selected:
1. Read the corresponding theme details from references/theme-details.md
2. Apply the specified colors (use exact hex codes for backgrounds, accents, text) and fonts (e.g. DejaVu Sans Bold for headers) consistently.
3. Verify contrast ratios meet accessibility standards where possible.
4. Maintain the theme's visual identity across all slides or pages.
5. For PPTX or DOCX artifacts, coordinate with pptx or docx skill to perform the style updates.

## Create Your Own Theme
When none of the existing themes fit:
1. Ask for description of desired mood, context, audience or specific colors/fonts.
2. Generate a new theme with a descriptive name (e.g. "Emerald City" for vibrant green tech).
3. Define 4-5 cohesive colors with hex codes and roles (primary accent, background, text, highlight).
4. Select complementary font pairings (e.g. DejaVu Sans Bold headers + DejaVu Sans body).
5. Show the proposed theme for review and verification, including best used for suggestion.
6. After approval, treat it as selected theme and apply using the process above. Add the new theme to references/theme-details.md for future use if appropriate.
